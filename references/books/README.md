## How to use them with this repo

1. Open Manning's brief to see the scope, then start the repo's
   [orientation](../../learning/lessons/00_orientation.md) and
   [indexing lesson](../../learning/lessons/01_indexing.md).
2. Use the O'Reilly contents PDF to locate the GPU/CUDA foundations and memory
   topics in chapters 6-7. Chapters 13-14 cover PyTorch profiling and the Triton
   compiler path. Reading those chapters requires access to the full book.
3. Use the freely readable [upstream tutorials](../../docs/REFERENCES.md#free-primary-technical-references)
   alongside our exercises while deciding whether to obtain a book.

The original downloaded files are unchanged. Their URLs, sizes, and SHA-256
checksums are recorded in [sources.json](sources.json). The PDF was checked for
its title, 14-page count, readable contents, and rendering.

Downloads are stored locally under `downloads/` and ignored by Git so the
portfolio does not redistribute book material. On a fresh clone, use the
online links above. Licensed personal ebook files can also be kept in that
ignored folder.
